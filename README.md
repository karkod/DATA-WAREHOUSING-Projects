#  E-Commerce Sales Data Warehouse


A complete, end-to-end data warehousing project for an online electronics store. This project demonstrates how to build a professional data warehouse using SQL, Python ETL, and Power BI dashboards.

✨ Overview

This is a semester-long data warehousing project that covers the complete lifecycle of a data warehouse from raw messy data to interactive business intelligence dashboards.

What it does:

- Collects sales data from multiple sources (website, mobile app, marketplace)
- Automatically cleans and loads data daily using Python ETL
- Organizes data in a star schema optimized for analysis
- Answers business questions with complex SQL queries
- Visualizes insights through interactive Power BI dashboards


# Project Architecture 🏗️

Raw Data (CSV) → ETL Pipeline (Python) → Data Warehouse (SQL) → Analytics → Dashboards (Power BI)

Components:

- Fact Table: Fact_Sales (500K+ transactions)
- Dimensions: Customer, Product, Date, Channel
- ETL: Automated daily Python pipeline
- Analytics: Multiple complex SQL queries
- Dashboards: 3 interactive Power BI dashboards

# Business Problem It Solves 💼

Without a warehouse: Answering "Which products are most profitable?" takes 3 hours or more of manual Excel work.

With this warehouse: Click a button → instant answer in 2 minutes.
